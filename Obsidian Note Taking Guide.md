## 2. Installation and Initial Setup

### On Desktop:

1. Go to the [Obsidian website](https://obsidian.md/download).
2. Download the version for Windows, Linux, or macOS.
3. Installation is very simple just like installing any other regular software.

### On Mobile:

- Search for "Obsidian" on Google Play or the App Store and install the app.
- Sync functionality is also available, but with the free plan, you can synchronize your folders using services like Google Drive or Dropbox.

### First Step:

- After installation, you need to create a **Vault**.
- A Vault is essentially a folder where all your notes and files are stored.
- You can have one Vault for everything or create separate Vaults (for example, for work, university, or personal projects).

## 3. Getting Familiar with Obsidian’s Structure

Once a Vault is created, the workspace consists of several main sections:

- **File Explorer**: On the left side, used to manage folders and files.
- **Note Editor**: The main area for writing notes.
- **Right Sidebar**: Displays details such as backlinks, tags, or graph view.
- **Graph View**: A network-style visualization of connections between your notes.

## 4. Basic Usage

### 4.1 Creating a Note

- Press **Ctrl + N** (or Cmd + N on Mac) to create a new note.
- Name the file; the file name will also serve as the note’s title.

### 4.2 Linking Notes

This is Obsidian’s core strength.

- To link to another note, simply use `[[File Name]]`.
    - If a note with that name doesn’t exist, it will be created automatically.

This feature works like a **personal wiki**, letting you build a network of interconnected notes.

### 4.3 Tags

- Tags are created with `#`.
- Example: `#study` or `#work`.
- Tags allow you to organize content in parallel to your folder structure.

### 4.4 Graph View

- Click **Graph** in the left toolbar.
- You’ll see a beautiful network of your notes and their connections.
- The more links you create, the more powerful and useful this graph becomes.

## 5. Note-Taking Structure

- After creating folders, you can add files inside each one.

#### 5.1 Headings

To structure your notes:

```sh
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
```

- The more `#` symbols, the smaller the heading.
- Typically, `#` is used for the main title, while `##` or `###` are for sub-sections.
- Remember to put a space between `#` and the text.

---

#### 5.2 Bold, Italic, and Strikethrough

```markdown
**Bold text**
*Italic text*
~~Strikethrough~~
```

**Output:**  

**Bold** – _Italic_ – ~~Strikethrough~~

---

#### 5.3 Lists

**Bullet List**

```sh

- Second item
    - Sub-item
```

**Output:**

- Second item

**Numbered List**

```sh

```

**Output:**

1. Item one
2. Item two
3. Item three

#### 5.4 Quote

To highlight or quote text:

```sh

```

**Output:**

## 6. Essential Shortcuts

To speed up your workflow:

- **Ctrl + N** → Create a new note
- **Ctrl + O** → Search and open a note
- **Ctrl + P** → Command Palette (quick access to all commands)
- **Ctrl + E** → Toggle between edit and preview mode
- **Ctrl + Shift + F** → Search across the entire Vault
- **Alt + Click** on a link → Open the note in a new window
- **Ctrl + B** → Bold selected text
- **Ctrl + D** → Delete lines

## 8. Best Practices for Organizing Notes (Workflow)

Having a powerful tool is not enough; without the right method, notes can quickly become messy and scattered. Here are some effective workflows that work great in Obsidian:

### 8.1 The PARA Method (Projects, Areas, Resources, Archive)

**Core Idea:** Organize all notes based on their **function**.

- **Projects** → Active projects, e.g., a paper in progress or a work assignment
- **Areas** → Ongoing areas of responsibility, e.g., health, learning, career
- **Resources** → References and source material, e.g., books, articles, tutorials
- **Archive** → Completed or outdated notes

**Example in Obsidian:**

```sh
Vault/
├── Projects/
│   ├── AI_Article.md
│   └── Web_Project.md
├── Areas/
│   ├── Health/
│   └── Planning/
├── Resources/
│   ├── Books/
│   └── Articles/
├── Archive/
│   ├── 2024
│   └── 2023
```

---

### 8.2 The Zettelkasten Method

**Perfect for research and idea generation:**

- Each note is small, self-contained, and given a **unique ID** (e.g., **20250902A**).
- Notes are interconnected with internal links to form a knowledge network.

**Practical Example:**

```sh
[[20250902A: Learning Theory]]
[[20250902B: Practical Example of Learning Theory]]
```

This method allows you to later discover relationships between ideas and build articles or even books.

---

### 8.3 The GTD Method (Getting Things Done)

**Great for task and project management:**

- **Inbox** → Collect all quick ideas and urgent tasks
- **Next Actions** → The very next steps to take
- **Projects** → Larger initiatives requiring multiple tasks
- **Waiting** → Tasks pending on others
- **Done** → Completed tasks

In Obsidian, this can be combined with **Daily Notes** and **Checklists** for a streamlined workflow.

## 9. Sync and Backup

One of the most important aspects of data management is **ensuring both accessibility and security of your notes**. Obsidian offers several options for this:

### 9.1 Obsidian Sync (Official)

- A paid service, but secure and fast.
- Automatic synchronization between desktop and mobile.
- Keeps version history, allowing you to roll back mistakes.

### 9.2 Free and Secure Methods

If you don’t want to use the paid service:

1. **Google Drive / Dropbox / OneDrive**
    
    - Place your Vault inside the sync folder.
    - Every change is automatically saved and synced.
    - Tip: Be careful not to sync files that are currently open to avoid conflicts.

2. **Git / GitHub**
    
    - Every Markdown note can be stored on GitHub easily.
    - Enables versioning and history recovery.
    - Perfect for developers or anyone who values security and version control.

3. **Syncthing**
    
    - A fully offline and secure tool for syncing between personal devices without cloud servers.
    - Great for those who prioritize high security and privacy.

4. **Manual Backup**
    
    - You can manually compress your Vault (e.g., `.zip`) and store or transfer it.
    - After extracting, it can be used on another system or mobile.
    - Recommended: encrypt the compressed file before storing or sharing.

### 9.3 Regular Backups

Even with sync, **regular backups are essential**.

- Keep a dedicated Backup folder on an external hard drive or NAS.    
- Copy your Vault daily or weekly.

## 10. Exporting Notes

One of Obsidian’s strengths is that you maintain full control over your notes and can export them into **various formats** for use or sharing.

### 10.1 PDF Export

- Ideal for **printing or sharing** individual notes or collections.
- Simple steps:
    
    1. Open the note you want.
    2. Select file → From the top-right options → Export to PDF.
    3. Adjust page settings, font size, and layout before confirming.

### 10.2 Markdown (.md) Export

- The native format of Obsidian.
- Main advantage: works seamlessly with **GitHub, AI tools, and other text editors**.
- Notes are saved as plain files, making them portable, easy to copy, and rebuild anytime.

### 10.3 HTML Export

- Great for sharing notes on a **website or blog**.
- Method:
    - Community plugins like **Markdown Export** or **Pandoc** can convert Markdown into HTML.
    - Links and formatting are preserved.

### 10.4 Word and Other Formats

- With tools like **Pandoc**, you can convert Markdown into **DOCX, LaTeX, EPUB, and more**.
- Excellent for those who want to transform their notes into a **book or publishable article**.
